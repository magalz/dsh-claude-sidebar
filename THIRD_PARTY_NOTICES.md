Changes made for dsh-claude-sidebar: the slot id, locale namespace, console tag, class
names and tooltip id prefix are ours; comments and console messages are English; the
aria-label fallback in `findToggleEl` and the unused cube icon are removed; the window
resize listener is now removed on cleanup; the rail no longer hides when the right sidebar
is open, it stays beside the open column and follows that column's width.
