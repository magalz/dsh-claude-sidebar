# dsh-claude-sidebar

A DeepSeek Harness (dsh) plugin that adds a Claude-desktop-style right sidebar with an icon rail, Jobs, Subagents, Environment and Git tabs, a Run button on chat code blocks, automatic pane sizing and an `open_in_browser` agent tool.

The source code arrives in the next pull request; this repository currently contains only repository setup and CI.
